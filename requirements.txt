# Uplers MCP server - deliberately thin.
# No database server; storage is stdlib sqlite3. A browser is needed for exactly
# one thing, signing in - see the playwright note at the bottom. It is never in
# the data path: every read, public or authenticated, is plain httpx.

# The upper bound is load-bearing, and its VALUE is a separate decision from its
# existence. Both were measured, not assumed.
#
# WHY A BOUND AT ALL: mcp 2.0.0 relocated mcp/server/fastmcp to
# mcp/server/mcpserver. The sibling naukri server declared `mcp[cli]>=1.25.0`
# unbounded and imports the old path unconditionally; on 2026-08-20 a clean
# resolve picked 2.0.0 and all 55 of its test modules died at collection
# ("5 deselected, 55 errors", zero tests run) while every LOCAL naukri run stayed
# green on a venv holding mcp 1.26.0 from before 2.0.0 shipped. An unbounded `>=`
# on a dependency that moves import paths is a time bomb whose fuse is lit by
# someone else's release, and a local venv cannot see it.
#
# WHY <3 AND NOT <2: this server survives that move. server.py:33-36 tries
# `from mcp.server import MCPServer` and falls back to the 1.x path, so it runs
# on both majors. Measured 2026-08-20 in a throwaway venv, no local packages
# borrowed: the resolve picked mcp 2.0.0, server.py imported, and the suite gave
# "443 passed, 1 skipped in 28.58s". Copying naukri's <2 would downgrade a server
# that already works on the newest major -- a cargo-culted fix, applied to a
# repo that does not have the problem.
#
# So the bound is set at the next UNKNOWN major, not the last known-good one.
# mcp 3.x is code nobody has run this server against; raising this to <4 is a
# decision to go test on 3.x first, not a routine version bump.
# tests/test_requirements_pins.py fails if this cap disappears OR narrows to <2.
mcp[cli]>=1.26,<3
httpx>=0.27

# Sign-in only, and only for the authenticated tier.
#
# Uplers mints its bearer token inside its own sign-in flow, so the only honest
# way to get one is to open the real login page and let the operator type. That
# is the ONLY thing this dependency does: `uplers_server/auth.py` is the single
# module allowed to import it, and once a token exists every request - public or
# authenticated - goes over httpx.
#
# The whole public tier works without it. Missing Playwright degrades exactly
# one tool (uplers_login), which says so and names the fix, rather than failing
# somewhere confusing. It also needs its browser binary:
#     pip install playwright && playwright install chromium
playwright>=1.40

# Tests only
pytest>=8.0
pytest-asyncio>=0.23
